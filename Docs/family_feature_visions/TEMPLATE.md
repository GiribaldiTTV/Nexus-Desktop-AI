# Family Feature Category Template

Family Feature Vision ID: `F<family>-FF<two digits>`
Parent FAM: `FAM-000`
Feature Category: `Durable product feature name`
Category-Level Purpose: `Describe the user outcome.`
USER-Facing Surfaces: `Name the visible surfaces, controls, flows, or non-UI outcomes.`
Experience Flow: `Describe the normal user journey and meaningful failure/recovery paths.`
Included Capabilities: `List what this feature actually provides.`
Explicit Non-Goals: `List excluded or future capabilities and their product boundaries.`
Durable Feature Element Inventory: `F<family>-FF<two digits>-E01 - element, behavior, and observable outcome.`
Deferred Feature Carryforward: `Capability, reason deferred, prerequisite, and user-visible behavior until available.`
Design Options: `List meaningful product alternatives and tradeoffs.`
Proof Expectations: `Name affected state, interaction, accessibility, privacy, failure, and recovery checks.`
